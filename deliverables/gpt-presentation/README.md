# GPT Presentation — Metric Depth with Camera in the Loop

## Run

Open `index.html` directly in a modern browser. For a local server, run:

```bash
python3 -m http.server 8000 -d gpt-presentation
```

Then visit `http://localhost:8000`.

## Controls

- Arrow keys or Space: next slide
- Left Arrow: previous slide
- `O`: overview grid
- `P`: presenter view with speaker notes
- `F`: fullscreen
- `H`: help overlay

The deck is self-contained and uses only local assets copied from the reference project.
