# ارائهٔ پایان‌نامه — تخمین عمق آگاه از دوربین

این پوشه شامل دو خروجی هم‌محتواست.

- `presentation.html` نسخهٔ تعاملی مرورگر است. فایل را با یک سرور محلی باز کنید تا ویدئوی اسلاید ۴ بدون محدودیت مرورگر اجرا شود.
- `تخمین-عمق-آگاه-از-دوربین.pptx` نسخهٔ قابل ارائه در PowerPoint است و ۴۳ اسلاید و یادداشت ارائه‌دهنده دارد.

کنترل‌های نسخهٔ HTML

- کلیدهای جهت راست و چپ یا دکمه‌های «بعدی» و «قبلی»
- کلید `N` برای نمایش یادداشت‌ها
- دکمهٔ «پخش ویدئو» در اسلاید ۴

برای اجرای محلی

```bash
python3 -m http.server 8000 --directory presentation-astra
```

سپس `http://localhost:8000/presentation.html` را باز کنید.
