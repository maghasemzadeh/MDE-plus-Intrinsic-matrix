# Camera-Aware Depth Estimation · Sol presentation

Open `index.html` in a modern browser. No build step or server is required.

## Controls

- `←` / `→` or `Space` move between slides
- `G` opens the slide overview
- `N` toggles speaker notes
- `F` requests fullscreen
- `Home` / `End` jump to the first or last slide

The deck is self-contained except for the optional Google Fonts import. Local image assets live in `assets/`.
